# proyecto_vehiculos
Esta aplicacion fue desarrollada para analizar un conjunto de datos sobre anuncios de venta de vehiculos en Estados Unidos con el fin de facilitar la visualizacion de informacion importante para la toma de decisiones. El proyecto permite explorar las caracteristicas de los autos mediante una interfaz web interactiva que procesa los datos cargados desde un archivo csv.

La funcionalidad principal incluye herramientas visuales que se activan mediante casillas de verificacion segun lo que el usuario quiera observar en ese momento. Por un lado existe un histograma diseñado para revisar la distribucion del kilometraje de los vehiculos en el inventario. Por otro lado se incluyo un grafico de dispersion que muestra la relacion directa entre el precio de venta y el kilometraje registrado en el odometro de cada unidad.

Para construir esta herramienta se utilizo el lenguaje de programacion Python junto con librerias especializadas como Pandas para el procesamiento de los datos y Plotly Express para generar las visualizaciones dinamicas. El despliegue de la aplicacion se realizo en la plataforma Render para que cualquier persona pueda acceder a ella mediante un navegador web.

El acceso a la aplicacion en vivo esta disponible en la siguiente direccion de internet: https://proyecto-vehiculos-68af.onrender.com/
